Grocery Delivery System Optimization
Overview
A transportation optimization project developed to minimize the total transportation cost of a grocery delivery system while satisfying warehouse supply and customer demand constraints.
The project models the distribution of grocery orders from three warehouses to four demand areas using Linear Programming and the Transportation Model.
Objectives
Minimize total transportation cost.
Satisfy warehouse supply constraints.
Meet customer demand requirements.
Determine the optimal shipment allocation between warehouses and demand areas.
Evaluate the model under different scenarios.
Methodology
The problem was formulated as a Linear Programming model using:
Decision variables
Objective function
Supply constraints
Demand constraints
Non-negativity constraints
The model was implemented and optimized using Microsoft Excel and OpenSolver.
Scenarios
The model was evaluated under different conditions, including:
Base Case
Increased Demand
Increased Transportation Costs
Tools
Microsoft Excel
OpenSolver
Linear Programming
Transportation Model
Operations Research
Project Outcome
The optimization model identified an efficient shipment allocation while satisfying all supply and demand constraints. Scenario analysis demonstrated the model's ability to adapt to changes in demand and transportation costs.
